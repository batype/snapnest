# 每天一个开源小项目 · 第 1 个：拾光 SnapNest

## 结论

选择「截图美化 + 隐私遮挡」。用视觉变化吸引首次点击，用重复的截图分享任务争取复用。第一版面向开发者、独立产品作者、产品经理和内容创作者，不把“全网用户每天使用”作为未经验证的承诺。

一个小工具的“容易传播”和“高频”经常存在取舍：很新奇的玩法未必能留住用户；纯效率工具有复用价值，但未必能在信息流里展示价值。截图工具能用一张处理前后对比图说明用途，也能进入已有的分享流程。

## 方向比较

以下是针对本项目受众的产品判断，不是流量统计、用户访谈或搜索量测量。

| 方向 | 吸引注意 | 复用潜力 | 单日实现成本 | 判断 |
| --- | --- | --- | --- | --- |
| 截图美化与遮挡 | 高：前后效果可直接展示 | 较高：教程、演示、汇报反复用 | 中 | 本次选择 |
| 文本清理与排版 | 中：效果需要解释 | 高：复制粘贴场景多 | 低 | 适合后续系列 |
| JSON 格式化与对比 | 中：更偏开发者 | 高：对目标群体实用 | 中 | 需要明确差异化 |
| 二维码与分享卡片 | 高：易展示 | 中：通常按需使用 | 低至中 | 适合特定细分场景 |

## 调研依据与边界

截至 2026-10-18 的公开资料检索中，[Open Screenshot](https://github.com/jitheshkt/open-screenshot) 已提供本地截图处理、渐变、标注和导出；[screenshot-beautifier](https://github.com/gnort67/screenshot-beautifier) 也提供背景、边框和偏好记忆。这些实例说明同类实现可行且竞争存在，不能据此证明本项目有高留存或会获得大量关注。

本次未复制上述项目代码。拾光的代码、界面和示例 SVG 为本次编写。功能本身不是技术壁垒，增长仍依赖定位、完成体验和发布节奏。

## 第一版定位

一句话：**把刚截下的图，变成愿意发出去的图。**

- 场景：开发者分享更新、运营发布教程、产品经理做功能汇报。
- 入口：已有截图直接粘贴，不增加登录或上传步骤。
- 关键路径：粘贴 → 选背景 → 检查隐私 → 下载或复制。
- 价值：处理在本地完成；无强制水印；六个足够区分的默认背景；支持分享常用比例。
- 控制范围：第一版不做账号、云存储、AI 调用、复杂画布、收费解锁。

## 已落地

纯 HTML / CSS / ES Modules / Canvas，零运行依赖。支持 PNG、JPG、WebP 导入；渐变、留白、阴影、圆角；五种画布方式；窗口边框、可选标题；实心遮挡与撤销；PNG/JPG 1×/2× 导出；支持的浏览器内复制图片；样式记忆；响应式中文页面；MIT 源码下载。

使用 25 MB / 2400 万像素输入限制和最长边 4096 px 导出上限控制浏览器内存。遮挡需要用户人工框选，不声称自动识别或自动脱敏。

## 如何验证它是否真的高频

先邀请 10–20 位经常分享截图的目标用户试用一周，收集其自愿反馈：首次是否完成导出、用在什么任务、是否第二次打开、是否拿它替代原有流程。第一轮重点看重复使用的原因，不用 GitHub 星标代替留存。

建议记录的决策指标（不是当前已达成数据）：

- 激活：第一次打开是否不需要解释就能导出。
- 复用：一周内是否在至少两个真实任务中使用。
- 摩擦：粘贴、权限、导出尺寸哪一步最容易失败。
- 传播：用户是否愿意分享处理前后对比，是否愿意推荐给同事。

项目目前不内置访问统计。若将来加入统计，应先明确告知且不采集用户截图或标题。

## 发布素材

标题备选：

> 每天一个开源小项目 01：我做了个截图美化工具，粘贴就能用

正文草稿（需要自行填写公开体验地址和 GitHub 仓库链接后发布）：

> 平时发教程、晒项目，总要给截图加个背景、处理一下私人信息。于是做了「拾光 SnapNest」。
>
> 粘贴截图 → 选一个背景 → 框住敏感信息 → 导出。支持常用分享比例、窗口边框、高清 PNG/JPG 和复制图片。
>
> 纯前端，图片在浏览器本地处理，无需注册，无强制水印。MIT 开源，可以自行部署。
>
> 这是“每天一个开源小项目”的第 1 个。欢迎带着真实使用场景提意见：你下一次分享截图，还缺哪一步？

15 秒演示：0–3 秒展示普通截图；3–6 秒粘贴并点预设；6–9 秒切换方图；9–12 秒框选遮挡；12–15 秒导出并展示前后对比。

优先发目标用户已经在的技术社区或自己的账号，先获取真实反馈。不要声称“全网首创”“必爆”“增长已验证”。公开仓库：https://github.com/batype/snapnest 。体验地址：https://batype.github.io/snapnest/ 。尚未代发任何社交平台内容。

## 后续顺序

只有在真实反馈支持时，再加入常用样式收藏、批量导出、快捷标注或浏览器扩展。先让一次粘贴和一次导出可靠，再扩大功能集。
