# 验证记录

验证日期：2026-10-18。环境：本机 Node.js 24、Codex 内置浏览器。以下区分实际验证和未覆盖的范围。

## 自动检查

- `npm test`：3 组测试全部通过。覆盖 80 种横竖图、极端长宽比、画布比例、留白与窗口边框组合，确认图片完整适配且不超出画布。
- 遮挡坐标：反向拖动、超出图片边界的坐标归一化与裁切。
- 偏好输入：限制数值和颜色范围；非法存储值回落；标题不从本地存储恢复。
- `node --check dist/app.mjs` 与开发服务脚本语法检查通过。
- 下载 ZIP 使用 Python zipfile 校验，未发现损坏条目。

## 浏览器实测

- 示例加载、背景预设切换、比例切换、标题显示。
- 在 Canvas 上拖动创建遮挡，遮挡计数和撤销/清空控件启用。
- 复制图片显示成功；未进一步验证粘贴到各个第三方应用。
- PNG 实际下载并通过 Pillow 读取：2400 × 2400；其中存在 125440 个精确等于遮挡填色的像素，确认遮挡已写入导出结果。
- JPG 实际下载并通过 Pillow 读取：JPEG 格式，2400 × 1800。
- 通过文件选择器导入真实 2400 × 2400 PNG 成功。
- 390 px 手机布局实测：页面未产生水平溢出，预览、预设与设置纵向排列。
- 浏览器警告和错误日志检查：未发现应用脚本错误。
- 本机源码 ZIP 入口返回 HTTP 200。

实测中修正了上传文件名包含“示例”时误显示“示例图片”的标签逻辑，改为独立维护图片来源状态。
